# Original mknoir.com

The section components and original shadcn button/card styles in this directory were recovered from the repository's original Git HEAD. The About memo and Work history retain that source content.

`Inter-Latin.woff2` is the same Inter variable font served by the existing personal site at `https://www.mknoir.com/_next/static/media/83afe278b6a6bb3c-s.p.3a6ba036.woff2` (verified October 8, 2026). It is locally bundled to preserve the original typography. Inter is licensed under the SIL Open Font License; see `Inter-OFL.txt`.

Intentional additions are the design picker, the user-requested Cornucopia Discovery and App links, and a small Thoughts / Coming soon section. The voice presentation follows the original, using the current cancellation-safe connection lifecycle and clear AI disclosure. Its DNA indicator only animates while a real connection is starting or stopping.

All appearance overrides are scoped under `.original-portfolio` in `src/styles/original.css`.
